# Architecture Decision Records

This directory contains proposed and accepted architecture decisions for Advanced Harness. Each record states its status; a `Proposed` ADR documents a recommendation and does not by itself authorize implementation or change current behavior.

| ADR | Title | Status | Scope |
| --- | --- | --- | --- |
| [ADR-001](0001-documentation-ownership-through-shared-skills.md) | Documentation Ownership Through Shared Skills | Proposed | Documentation ownership and quality assurance |
| [ADR-002](0002-consolidate-agent-responsibilities.md) | Consolidate Agent Responsibilities While Preserving Specialized Reasoning and Independent Review | Proposed | Agent architecture and workflow orchestration |
| [ADR-003](0003-multi-methodology-development-architecture.md) | Multi-Methodology Development Architecture | Proposed | Methodology selection, scope, and governance |
